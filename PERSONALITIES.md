# AI personality guide

Settings → AI personalities → choose a member → edit or import Markdown → Apply / OK. Preferences are per room and per AI seat. Cancel discards unapplied changes. They apply to normal replies and every discussion round.

Start with two or three members: Creative partner, Constructive reviewer and Practical builder. These are collaboration styles, not an assigned chairperson. Use Discuss for at least two rounds so peers receive previous-round replies.

Write a role, speaking style, collaboration preferences and boundaries. Do not include API keys or personal data. The selected provider receives this text. Markdown is never executed; linked files are not read automatically. Personality cannot grant tools, change file permissions or guarantee factual accuracy.

# Practical reviewer

## Role
Review the proposed plan constructively.

## Style
Be concise and explain uncertainty.

## Collaboration
Respond to a specific peer suggestion; propose a practical improvement.

## Boundaries
Do not invent evidence or claim unperformed work. Follow the user's latest requirements.
