# Changelog

## v1.0 — 2026-11-12

First public Windows x64 release, under the MIT license.

- Downloadable standalone EXE with Python, Tcl/Tk and Pillow included; no Python or pip installation is required for end users.
- Named groups, multiple model/API connections, optional local agents, free discussion, pause and human participation.
- LAN browser participation and full transcript export in Markdown, text or JSON.
- Five UI languages and five guides: Simplified Chinese, Traditional Chinese, English, Japanese and Korean.
- Light/dark themes, full chat wallpaper, custom avatars and global/per-group nicknames.
- Unified settings, chat input options, local data folder access and About.
- Consistent application/Windows file versions, GitHub build workflow, offline EXE diagnostic and release checksums.

Only Windows x64 binaries are released. Local agents require their own installation/authentication; API providers require suitable credentials.

Pre-public development builds v0.3–v0.10 are superseded by this public release.
